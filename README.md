# akfamily.xyz

[AKFamily](https://github.com/akfamily) 主页 <https://akfamily.xyz> 的源码，由 GitHub Pages 直接发布 `main` 分支根目录。

纯静态页面，没有构建步骤：

- `index.html`：主页
- `404.html`：404 页面
- `assets/style.css`：样式
- `assets/img/`：二维码和截图
- `CNAME`：自定义域名

本地预览：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。
