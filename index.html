开源项目

AKShare

开源财经数据接口库

基于 Python 的财经数据接口库，提供股票、期货、期权、基金、外汇、债券、指数、加密货币等金融产品的基本面数据、实时和历史行情数据，以及宏观经济等另类数据，一行代码返回 pandas DataFrame。

pip install akshare

文档数据字典GitHub

AKQuant

高性能量化投研框架

核心引擎由 Rust 编写，提供 Python 策略接口，内置滚动训练、TA-Lib 兼容指标、因子表达式引擎、参数优化和风控模块，覆盖从回测到实盘的完整流程。

pip install akquant

文档EnglishGitHub

AKTools

AKShare 的 HTTP API 与 MCP 服务

一行命令启动 HTTP 服务，让 Java、Go、R、MATLAB、Excel 等任何语言和软件都能使用 AKShare 的数据；也可以作为 MCP 服务接入 Claude、Cursor 等 AI 助手，用自然语言取数。

pip install aktools

文档MCP 指南GitHub
